# bozh3ng.github.io

Personal website of Bo Zheng -- mathematics, machine learning, and things in between.

Live at [bozh3ng.github.io](https://bozh3ng.github.io/).

Built with [al-folio](https://github.com/alshedivat/al-folio), a Jekyll theme for academics. Hosted on GitHub Pages.

## Local Development

```bash
bundle install
bundle exec jekyll serve
```
